<p align="center">

  <br>
  <br>
  🎓 Currently pursuing my PhD at <b>University of Copenhagen (DIKU)</b>  
  <br>
  💊 Research focus: <b>causal inference and representation learning</b> applied to EHR data

  <br>
  🔍 Developing <a href="https://github.com/kirilklein/PHAIR_EHR"><b>Causal-CORE-BEHRT</b></a> — causal extensions for scalable pharmacovigilance analyses  
  <br>
  💬 Interested in ML for healthcare
